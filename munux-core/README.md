# Munux Core

This is the core kernel of the Munux operating system — a fully functional, polyglot OS kernel implementing fundamental concepts including memory management, process scheduling, interrupt handling, and device drivers. Source is split between **C (C99, freestanding)**, **x86 Assembly (NASM)**, and **Rust (`no_std`, edition 2021)**, with each language used where it provides the most leverage.

## Features

### Interrupt Management
- Complete IDT (Interrupt Descriptor Table) with 256 entries
- CPU exception handlers for all x86 exceptions
- Hardware IRQ management with PIC reprogramming
- Extensible interrupt handler registration system

### Memory Management
- **Physical Memory Manager**: Bitmap-based frame allocation for 4KB pages
- **Virtual Memory Manager**: Full paging support with page directory and page tables
- **Heap Allocator**: First-fit allocator with adjacent-block coalescing, implemented in safe Rust; exposed through the existing C `kmalloc` / `kfree` entry points
- Memory protection and isolation between kernel spaces
- IRQ-safe locking via a handrolled `IrqMutex<T>` ready for SMP

### Process Management
- Process Control Block (PCB) structure with complete state tracking
- Round-robin scheduler with four priority levels
- Preemptive multitasking with quantum-based time slicing
- Context switching implemented in optimized assembly
- Support for process creation, termination, and state transitions

### Device Drivers
- **Timer (PIT)**: Programmable Interval Timer for scheduling and timekeeping
- **Keyboard**: Complete PS/2 keyboard driver with ABNT2 layout, modifier keys, and circular buffer
- **Mouse**: PS/2 mouse driver with three-button support and movement tracking
- **Serial Port**: RS-232 communication for debugging and external device communication
- **Disk**: ATA/IDE disk controller with sector-level read/write operations

### Rust Subsystem (v0.3+)

A `no_std` Rust workspace under [`kernel/rust/`](kernel/rust/) compiles to a static library (`libmunux_rs.a`) that is linked into the kernel ELF. It hosts the heap allocator and shared safe-Rust primitives (`IrqMutex`). The FFI surface is generated by `cbindgen` and committed at [`kernel/rust/include/munux_rs.h`](kernel/rust/include/munux_rs.h).

## Building

### Prerequisites

- **i686-elf-gcc**: Cross-compiler for bare-metal x86
- **i686-elf-binutils**: Binary utilities (linker, assembler)
- **NASM**: Netwide Assembler for bootloader and stubs
- **rustup** + **nightly toolchain** + `rust-src` component: Rust workspace under [`kernel/rust/`](kernel/rust/)
- **cbindgen**: C header generator (only needed when regenerating `munux_rs.h`)
- **GRUB**: `grub-mkrescue` for creating bootable ISOs
- **QEMU**: x86 system emulator for testing

### Compilation

```bash
make             # Build everything (C + Assembly + Rust)
make clean       # Remove build artifacts
make run         # Build and run in QEMU
make debug       # Build and start with GDB server
make test        # Run automated tests
make rust        # Build only libmunux_rs.a
make rust-check  # cargo check + clippy -D warnings
make rust-fmt    # cargo fmt --check
make rust-headers  # regenerate kernel/rust/include/munux_rs.h
```
